# Application lens

- State the operational need, stakeholder constraints, deployment environment, cost of error, and accepted practice.
- Distinguish application novelty from algorithm novelty and verify that domain constraints materially shape the method.
- Inspect representative scenarios, external validity, robustness, safety, latency, maintenance, and resource cost.
- Check whether evaluation metrics correspond to operational outcomes rather than only proxy accuracy.
- Treat deployment claims as unsupported when evidence is limited to idealized simulation.
