# Source Basis

Use this file when a user asks why a reproducibility rule exists, wants source justification, or needs to audit `ieee-data` against IEEE-facing sources.

## Source map

| Skill rule | Primary support |
|---|---|
| Use IEEE templates and target-journal instructions before generic data-statement habits. | IEEE Article Templates explain that journal templates place required article elements and guide abbreviations/acronyms; target journals can add stricter requirements. |
| Supplementary files may include data, code, multimedia, derivations, and proof details when they enhance the paper. | IEEE supplementary-material guidance and IEEE society author pages describe supplementary materials such as datasets, software, multimedia, videos, and detailed algebra/proofs. |
| Dataset and code packages need stable locations and clear descriptions. | IEEE DataPort and IEEE supplementary-material guidance expect downloadable, discoverable files with enough context for reader use. |
| Graphics and figure source files must use IEEE-compatible formats. | IEEE Author Center graphics guidance lists accepted graphics formats and limits JPEG use to author photos. |
| T-ASE papers should prepare data/materials for accepted-paper handling and support reproducible evaluation. | T-ASE submitted/final-manuscript checklists require practical automation evidence and final package compliance. |
| Control and networked-system papers need enough assumptions, parameters, models, and proof/simulation evidence for verification. | TAC, TCST, and TCNS author information define technical scope and IEEE double-column submission expectations. |
| Conference extensions must disclose prior versions and added archival value. | CSS journal author information pages require clear citation of prior conference work and explanation of added value. |
