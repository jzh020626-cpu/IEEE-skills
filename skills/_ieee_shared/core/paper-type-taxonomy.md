# IEEE Paper Type Taxonomy

Classify the manuscript before writing or review:

- Algorithmic / theoretical: problem formulation, assumptions, theorem/proof, complexity, convergence or stability.
- Robotic / automation system: task scenario, platform, sensing/actuation, controller or planner, experiments, safety and deployment constraints.
- Communication / networked control: channel/load model, delay/drop/retransmission, protocol, scalability, reliability, latency, throughput.
- Industrial informatics / cyber-physical systems: architecture, data flow, edge/cloud split, real-time constraints, ablations, deployment risk.
- Survey / tutorial: taxonomy, comparison table, unresolved challenges, future directions.
