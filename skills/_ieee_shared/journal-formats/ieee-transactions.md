# IEEE Transactions Venue Facts

Use this file only as a compact venue-format memory. For strict pre-submission decisions, verify the current journal author page and then apply `../core/ieee-transactions-contract.md`.

## Common IEEE Journal Format

- Use the IEEE article template or IEEEtran journal mode when writing LaTeX.
- Prepare a double-column manuscript unless the target journal explicitly asks otherwise.
- Include Abstract and Index Terms before the main text.
- Use numeric IEEE citations in square brackets and order references by first citation.
- Use IEEE-compatible figure formats: PS, EPS, PDF, PNG, or TIFF for graphics; high-resolution JPEG is for author photos only.
- Include ORCID information where the submission system requires it.

## Frequent Target Limits

| Venue | Initial hard audit point |

| T-ASE | Note to Practitioners required; double-anonymous hygiene for review; final overlength charge applies past the journal's page thresholds. |

| TAC | Full Papers normally around 12 pages and no more than 16; Technical Notes/Correspondence normally around 6 and no more than 8. |
| TCST | Papers no longer than 16 pages; Brief Papers no longer than 8; Letters no longer than 4. |
| TCNS | Double-column 10-pt IEEE format; audit against the current 12-page total / 10-page main-text convention and self-citation limits. |

## Front-Matter Reminders

- Do not put citations, numbered equations, or footnotes in the Abstract.
- Do not replace Index Terms with a journal-style keyword list unless the target explicitly permits it.
- For T-ASE, the Note to Practitioners must explain application value, limitations, and near-term use without duplicating the Abstract.
