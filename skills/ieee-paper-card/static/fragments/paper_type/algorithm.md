# Algorithm lens

- Reconstruct inputs, outputs, objective, constraints, assumptions, modules, training/solution procedure, inference/execution path, and complexity.
- Distinguish the actual algorithmic contribution from a combination of known components.
- Map every claimed advantage to baselines, ablations, sensitivity tests, uncertainty, and failure cases.
- Check whether comparisons use aligned information, compute, tuning effort, data, and safety constraints.
- For learning methods, inspect splits, leakage, seeds, hyperparameter selection, generalization, and deployment shift.
