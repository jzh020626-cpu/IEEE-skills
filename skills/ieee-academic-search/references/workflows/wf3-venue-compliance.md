# Workflow 3: Target-Venue Compliance Search

**Purpose:** Verify current official target-venue instructions before giving submission-critical advice.

## Procedure

1. Identify venue and paper type: T-ASE, TII, TAC, TCST, TCNS, T-RO/RA-L, TIE, TWC, TCOM, IoT-J, or generic IEEE.
2. Open official sources first:
   - IEEE Author Center for templates, editorial style, graphics, and supplementary materials.
   - Society or journal page for scope, page limits, article types, special sections, and checklists.
3. Extract the hard constraints:
   - template / double-column / IEEEtran
   - Abstract and Index Terms rules
   - page limits and overlength charges
   - Note to Practitioners or other venue-specific front matter
   - anonymity, ORCID, supplement, figure, and final-file requirements
4. Compare against the user's manuscript or target plan.
5. Return source links and date checked.

- [URL]

- [constraint]

- [item requiring compiled PDF/submission-system confirmation]
