# IEEE Journal Scope

Default scope is IEEE-first archival literature for robotics, automation, control, communications, and industrial informatics. Verify exact venue names and publication status when a strict target list matters.

## Core targets

- IEEE Transactions on Automation Science and Engineering (T-ASE)
- IEEE Transactions on Industrial Informatics (TII)
- IEEE Transactions on Robotics (T-RO)
- IEEE Robotics and Automation Letters (RA-L)
- IEEE Transactions on Automatic Control (TAC)
- IEEE Transactions on Control Systems Technology (TCST)
- IEEE Transactions on Industrial Electronics (TIE)
- IEEE/ASME Transactions on Mechatronics
- IEEE Transactions on Intelligent Transportation Systems
- IEEE Transactions on Wireless Communications (TWC)
- IEEE Transactions on Communications (TCOM)
- IEEE Internet of Things Journal
- IEEE Transactions on Network Science and Engineering
- IEEE Transactions on Mobile Computing
- IEEE Transactions on Cybernetics
- IEEE Transactions on Systems, Man, and Cybernetics: Systems

## Scope modes

- `tase`: T-ASE-focused automation science and engineering support.
- `tii`: TII-focused industrial informatics and cyber-physical systems support.
- `robotics`: robotics, automation, mechatronics, intelligent vehicles, and RA-L/T-RO/T-ASE.
- `control`: TAC, TCST, systems/control/cybernetics, and networked control.
- `communications`: TWC, TCOM, IoT-J, mobile computing, network science, and vehicular technology.
- `industrial`: TII, TIE, industrial cyber-physical systems, edge intelligence, reliability, and real-time deployment.
- `all`: all bundled IEEE-first targets.

Use non-IEEE sources only when they are the canonical baseline, dataset, theory source, or the user explicitly asks for broader coverage.
