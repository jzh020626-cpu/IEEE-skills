# Independent specialist-lens review

Use role lenses as an internal review method, not invented people and not automatic sub-agent dispatch. Select only the lenses activated by the proposal's failure modes, for example control theory, robotics systems, wireless networking, statistics, reproducibility, safety, or venue fit.

Each lens independently reads the same frozen foundation files and returns: the challenged claim, supplied evidence, missing evidence, severity, and closure test. Do not let one lens read another lens's findings before its own pass is complete. Reconcile conflicts only afterward and never manufacture consensus.
