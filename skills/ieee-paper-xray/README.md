# `ieee-paper-xray`：论文推理精读

[English](README_EN.md)

重建工程论文的方法逻辑、关键公式和证据边界。

## 适用任务

重建工程论文的方法逻辑、关键公式和证据边界。

## 典型请求

解释这篇控制论文为什么这样设计，并用小例子算清关键公式。

## 需要提供

论文正文及可用附录；可指定章节、公式和阅读语言。

## 产出

带来源锚点的解释、明确标注的教学算例、假设与证据缺口。

## 边界

不代替全文双语 reader、01–16 Paper Card 或独立审稿。

## 相关技能

ieee-reader、ieee-paper-card、ieee-reviewer
