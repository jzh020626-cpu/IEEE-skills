# IEEE Transactions Figure Observations

This file mirrors `ieee-2026-observations.md` for older references. Use the current robotics/control/communications archetypes there as the authority.

Key defaults:

- system-model composite for architecture and task setup
- trajectory/time-response panels for control and robotics evidence
- communications/network constraint panels for latency, throughput, packet loss, and reliability
- benchmark/ablation grids for method comparison
- hardware/simulation evidence panels only when they prove setup, feasibility, or failure mode

Do not import non-IEEE caption conventions or legacy demonstration labels into IEEE Transactions figures.
