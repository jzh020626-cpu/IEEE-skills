# Source basis

Use this file to keep `ieee-response` grounded in IEEE journal revision practice, target-journal instructions, and the editor decision letter.

## Source hierarchy

1. Target journal instructions and the specific editor decision letter.
2. IEEE Author Center / IEEE society pages for submission and revision package requirements.
3. T-ASE, TII, TAC, TCST, TCNS author information when the response is venue-specific.
4. Local manuscript facts supplied by the author.

If a current journal page conflicts with this file, follow the current journal page.

## Implementation implications

- Point-by-point response is the default structure for revision cases.
- Preserve each reviewer concern before the response unless the user asks for a compact response table.
- Every criticism must be answered, cross-referenced to manuscript changes, or flagged as unresolved.
- Do not concede unsupported claims; revise the claim, add evidence, or state a limitation.
- For page-limited IEEE venues, every proposed addition must have a compression plan.
- For conference extensions, explicitly state new archival contributions.
