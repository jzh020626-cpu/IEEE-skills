# `ieee-paper2word`：论文 Word 排版

[English](README_EN.md)

把工程论文 Markdown 排为可编辑 Word，或从参考文档提取格式要求。

## 适用任务

把工程论文 Markdown 排为可编辑 Word，或从参考文档提取格式要求。

## 典型请求

按提供的 IEEE Word 模板排版这份 Markdown，保留原稿和公式。

## 需要提供

稿件、图件、参考文献；期刊名及模板或格式要求（如有）。

## 产出

DOCX、格式来源说明和页面 QA；可选提取的段落格式样本。

## 边界

可选引擎另行安装；必须显式指定 IEEE 格式，不能把默认样式当成投稿合规。

## 相关技能

ieee-writing、ieee-polishing、ieee-submission-audit
