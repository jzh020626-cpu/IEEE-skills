# IEEE Transactions shared layer

Shared guidance for the IEEE Transactions skills. Keep this directory alongside the `ieee-*` skill folders; router skills load these files by relative path.

`core/claim-centered-writing.md` contains the suite's evidence-calibrated
press-release principle. It keeps the main manuscript focused on the strongest
supported claim while routing non-leading audit detail to the supplement or
artifact record without permitting selective reporting or evasive responses.

The shared layer also provides engineering evidence-chain alignment,
main-text evidence allocation, Discussion modality/argument control,
cross-section consistency, and conditional engineering research compliance.
