# ieee-figure

IEEE Transactions figure workflow for robotics, automation, control,
communications, and industrial informatics. It includes claim-led multi-panel
architecture, Python/R backend isolation, source validation, PDF glyph checks,
render-time panel alignment, rendered collision auditing, and final-size visual
QA. Graphical-abstract assistance is routed through an explicit policy and
provenance gate. See `SKILL.md` for agent instructions.
