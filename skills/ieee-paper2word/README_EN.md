# `ieee-paper2word` Skill

[中文说明](README.md)

Format engineering Markdown as editable Word or extract requirements from reference documents.

## What To Use It For

Format engineering Markdown as editable Word or extract requirements from reference documents.

## Typical Requests

Format this Markdown using the supplied IEEE Word template and preserve the source and equations.

## What You Need To Provide

Manuscript, figures, references and any target journal, template or formatting requirements.

## Outputs

DOCX, formatting provenance and rendered page QA; optional paragraph-layout samples.

## Boundaries

The optional engine is installed separately. Explicit IEEE requirements are required; default styling does not establish compliance.

## Related Skills

ieee-writing, ieee-polishing, ieee-submission-audit
