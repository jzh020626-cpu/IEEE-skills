# Source hierarchy

Use the strongest available source for each field:

1. Official version-of-record page or PDF from IEEE Xplore, the conference/journal publisher, standards body, or issuing institution.
2. DOI registration metadata such as Crossref, checked against the version of record.
3. Official proceedings, journal table of contents, arXiv record, institutional repository, or standards catalog.
4. Curated discipline indexes such as DBLP for identity support.
5. Bibliographic exports, search snippets, Google Scholar, or user libraries only as discovery leads.

For IEEE records, use IEEE Xplore to resolve legacy metadata and article numbers when Crossref is incomplete. For a non-IEEE venue, use that publisher's official record. Record unavailable sources and do not convert partial coverage into certainty.
