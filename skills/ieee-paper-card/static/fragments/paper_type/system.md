# System lens

- Reconstruct architecture, interfaces, timing, information flow, hardware/software stack, operating envelope, and safety boundaries.
- Separate component novelty from integration value and from demonstrated end-to-end capability.
- Check latency, throughput, reliability, resource use, scalability, fault cases, and real-time feasibility.
- For robotics, distinguish simulation, hardware-in-the-loop, lab, and field evidence; inspect sim-to-real transfer and recovery behavior.
- Require evidence that the whole system, not only an isolated component, supports the headline claim.
